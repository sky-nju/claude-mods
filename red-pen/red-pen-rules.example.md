# 我的红笔规矩

> 复制到 `.claude/red-pen-rules.md`（项目里）或 `~/.claude/red-pen-rules.md`（所有项目），按自己的习惯改。
> 一行一条，写清楚什么算问题、什么不算。红笔每批一条回答都会读整份文件。

1. 黑话：不用没解释的英文词、术语和代号；非用不可，就在第一次出现时用一句大白话解释。团队常识不算黑话，也不用解释：DAU、PRD、PM、AI、API、Bug（换成你们团队的常用词）。
2. 自造词：不自创生僻的简写标签（如「线A」「三件套」），改成一眼能懂的描述。
3. 结论在前：第一句就是结论或答案；背景和出处放到最后。
4. 数字成堆：一句话里不堆 3 个以上数字，数字放进表格或列表。
5. 过程话：不写「下面我来…」「总结一下」「好问题」这类话。
6. 重复：多轮修改只给改动的部分，不复述整份旧方案。
7. 排版：密密麻麻的整段，写成「加粗结论 + 2–4 个要点」。
