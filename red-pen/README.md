# 红笔批阅

一个 Claude Code 的 mod：让你像改稿子一样批 Claude 的回答。

- **逐段批阅**：鼠标停在回答的某一段上，段落末尾会出现「✎」。点它展开「采纳 / 不要 / 啥意思 / 批注」，批完几段，一键发出。发出去的是你平时手打的格式：

  ```
  方案 1.1 加一句……——不要
  方案二、预算……——不用写这么细
  其余都采纳
  ```

- **啥意思**：看不懂某段里的词，点「啥意思」。Claude 会带着整段对话解释，解释只显示在这段下面，不会进主对话。问过的词记进「看不懂词典」，下次开会话时提醒 Claude 少用这些词，或者先解释。
- **自动红笔**：超过 300 字的回答结束后，会用一个便宜的小模型按规矩批一遍。挑出的问题（黑话、自造词、数字成堆、结论不在前……）列在回答下面，每条可以点「照改」或「这条不算」。点过「这条不算」的例子会告诉小模型，同类问题以后少挑。
- **面板**：输入 `/redpen` 打开面板，里面有批阅篮、今天批了多少、两个开关（段落按钮、自动红笔）和看不懂词典。

## 安装

需要 Claude Code 2.1.287 或以上。在终端里运行：

```bash
claude plugin install red-pen --marketplace sky-nju/claude-mods
```

或者在终端里的 Claude Code 对话框中输入 `/plugin install red-pen --marketplace sky-nju/claude-mods`。第一次会问要不要添加这个插件市场，选 `y`，范围选用户级（user）。

桌面 App 的 Code 页里不能运行安装命令，要先在终端装一次。装好后，桌面 App 新开的会话也会自动加载。

**更新**：

```bash
claude plugin marketplace update sky-claude-mods
```

然后在会话里输入 `/reload-plugins`，或者新开一个会话。

## 换成自己的规矩

默认用内置的 6 条「说人话」规矩。想用自己的，就新建一个文件 `.claude/red-pen-rules.md`，可以放在项目目录下（只对这个项目生效），也可以放在 home 目录下（`~/.claude/red-pen-rules.md`，对所有项目生效）。写法参考 [red-pen-rules.example.md](red-pen-rules.example.md)：一行一条，写清楚哪些不算问题。改完下次开会话生效。

## 花费和数据

- **啥意思**：用你当前会话的模型，带着整段对话问一次。会话越长，读的缓存越多，所以只在你点的时候才问。
- **自动红笔**：用 haiku 小模型，只看这一条回答，不带对话历史。如果你的环境里调不到 haiku（比如接的是别的模型网关），自动红笔会安静地不出现，其他功能照常能用。
- 批阅篮、词典和统计只存在你本机的 Claude Code 里，不会发到别的地方。

## 已知限制

- 鼠标悬停的显示由界面自己控制，插件没法加延迟，所以采用「先点 ✎ 再展开」的方式，避免划过时内容跳动。
- 桌面 App 读不到鼠标选中的文字，所以只能按段批，不能划选任意一句。
- 手机端和 VS Code 的对话面板不显示 mod 画的内容。
