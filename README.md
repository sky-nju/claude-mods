# claude-mods

Sky 做的 Claude Code mods。mod 是装进 Claude Code 的一小段代码，可以改 Claude Code 自己的界面和行为。

| mod | 做什么 | 安装 |
|---|---|---|
| [红笔批阅 red-pen](red-pen/) | 在 Claude 的回答上逐段批「采纳 / 不要 / 啥意思 / 批注」，一键拼成「原文——批注」发出；长回答自动按规矩批一遍 | `claude plugin install red-pen --marketplace sky-nju/claude-mods` |

需要 Claude Code 2.1.287 或以上，安装命令在终端里运行。装好后，终端和桌面 App 的会话都会加载。
